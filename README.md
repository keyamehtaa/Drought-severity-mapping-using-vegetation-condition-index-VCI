The following steps were performed in Google Earth Engine:  Defined the Area of Interest (Vidharba)  Loaded Sen nel-2 dataset  Filtered data based on date and cloud cover  Calculated NDVI using Red and NIR bands NDVI = (NIR – Red) / (NIR + Red) o Higher NDVI values indicate healthier vegetation, lower values indicate stressed vegetation  Calculated minimum and maximum NDVI values  Applied the VCI formula: VCI = (NDVI - NDVImin) / (NDVImax - NDVImin) × 100 o Classifica on VCI < 20 : Extreme Drought 20 – 40 : Moderate Drought 40 – 60 : Mild Drought
